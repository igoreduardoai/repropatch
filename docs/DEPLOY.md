# Authenticated deployment

Verified URL (27 October 2026):
https://tan-pastor-holidays-westminster.trycloudflare.com

This is a **free temporary HTTPS tunnel to the Mac**, not permanent cloud hosting.
It requires this Mac, Docker and the local processes to remain online. SQLite,
reviewed cases and artifacts persist in `<repo>/.data`.
No paid hosting service, domain or subscription was purchased.

The UI is visible, while every `/api/*` route requires the operator Bearer token.
`/healthz` is intentionally public. The token is generated by local setup and
stored in the private `.env`; it is not a Meta credential. The Meta credential
never enters web assets, target containers, videos or submission artifacts.

Local service command (one API + one separate worker):

```bash
bash scripts/start_local.sh
```

The tested temporary tunnel command deliberately ignores unrelated global config:

```bash
cloudflared --config /dev/null tunnel --url http://127.0.0.1:8000 \
  --no-autoupdate --protocol http2
```

Restarting the tunnel generally gives a different URL. No DNS or existing named
tunnel configuration was changed. Logs for this execution are in `.data/`.

LIVE was enabled only after actual Meta repairs passed the complete path.
Registered case acceptance, video SHA, $3/run and $24 persistent batch budget are
rechecked. An interrupted reservation becomes UNKNOWN and halts new calls until
reconciled. The startup does not replay completed or interrupted jobs.

This is an operator demonstration with reviewed targets, not a multi-tenant
service accepting arbitrary hostile repositories. The public API does not expose
shell commands, repository paths or the Docker socket. A dedicated worker VM is
required before expanding that threat model.
