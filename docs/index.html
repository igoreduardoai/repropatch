ReproPatch

Show the bug, keep the proof. Bug video → frozen, hashed reproduction test → Meta muse-wonder-1.0 patches the code through 11 sandboxed tools → an independent evaluator the model never sees decides the verdict.

Judge in 2 minutes

  1. Watch a real run (terminal recording of a live Meta run, below): pick one where the model said "Fixed" and the hidden check said no.
  2. Scan the scoreboard: every counted run on every real bug, with the upstream fix, the bug video, and the verdict.
  3. Re-check it yourself offline, standard library only, no keys, runs in under a second: 
    git clone https://github.com/igoreduardoai/repropatch && cd repropatch && python3 scripts/verify_evidence.py
    It recomputes patch, frozen-test and bug-video SHA-256 hashes and re-tallies every run and every metered Meta call.
  4. Demo video (≤3 min): YouTube · step-by-step replay of the first repair: replay/ · limits: VALIDATION.md
